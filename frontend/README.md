# Frontend - React

React + Bootstrap frontend for StudentCare+ system.

## Structure

### src/
- Components: Reusable UI components
- Pages: Main application pages
- Hooks: Custom React hooks
- Services: API integration

### public/
- Static assets
- Index.html

## User Interfaces
- Student Dashboard
- Clinic Staff Interface
- Adviser Portal
- Admin Panel

## Setup
```bash
npm install
npm start
```

## Build
```bash
npm run build
```
