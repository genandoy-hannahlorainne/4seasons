Backup Information

  • Backups are stored on the server inside the application storage folder
  • Download backups regularly to keep an offline copy
  • Backups include all database tables and data
  • Restore will replace ALL current data with backup data and cannot be undone

Before Restoring

  • Create a new backup of current data first
  • Make sure you selected the correct backup file
  • All data created after the backup date will be permanently lost
