ℹ️ Backup Information

  • Backups are stored securely on the server
  • Download backups to keep an offline copy
  • Old backups are automatically cleaned up after 30 days
  • Backups include all database tables and data
  • ⚠️ Restore will replace ALL current data with backup data

⚠️ Important: About Restore

Restoring a backup will:

  • Replace ALL current database data with the backup data
  • Delete any changes made after the backup date
  • Cannot be undone once completed

Before restoring:

  • Create a new backup of current data first
  • Ensure you selected the correct backup file
  • Notify all users that the system will be temporarily unavailable
