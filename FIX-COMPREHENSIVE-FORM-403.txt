HOW TO FIX: SHDF Comprehensive Form 403 Unauthorized Error
============================================================

PROBLEM:
When submitting the comprehensive SHDF form, you get:
"This action is unauthorized" with HTTP 403 error

CAUSE:
The student's user account is not properly linked or has wrong permissions.

QUICK FIX:
----------

Step 1: Check which student is having the issue
(Look at the browser console or form to see the student_id)

Step 2: Run diagnostic command
cd backend-laravel
php artisan student:check-user-mapping {student_id}

Step 3: Follow the prompts
The command will tell you what's wrong and offer to fix it automatically.

MANUAL FIX (if command doesn't work):
--------------------------------------

1. Find the student's user_id:
   SELECT student_id, user_id, first_name, last_name 
   FROM students 
   WHERE student_id = {student_id};

2. If user_id is NULL, find the matching user:
   SELECT user_id, email FROM users WHERE email LIKE '%{student_id}%';

3. Link them:
   UPDATE students SET user_id = {found_user_id} WHERE student_id = {student_id};

4. Verify the user has Student role:
   SELECT u.user_id, u.email, r.role_name 
   FROM users u 
   LEFT JOIN roles r ON u.role_id = r.id 
   WHERE u.user_id = {user_id};

5. If role is wrong, fix it:
   UPDATE users SET role_id = (SELECT id FROM roles WHERE role_name = 'Student') 
   WHERE user_id = {user_id};

AFTER FIX:
----------
- Student should be able to submit the comprehensive form
- No more 403 errors
- Form will save successfully

CHECK LOGS:
-----------
After attempting to submit, check:
tail -f backend-laravel/storage/logs/laravel.log

Look for "[SHDF Form Request] Authorization check" to see details.
