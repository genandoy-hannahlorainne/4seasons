HOW TO FIX STUDENT 136883100331 SHDF ACCESS ISSUE
==================================================

PROBLEM:
Student 136883100331 cannot access the basic SHDF form because the system 
incorrectly thinks they already completed it.

SOLUTION (2 simple commands):
-----------------------------

1. Check the status:
   cd backend-laravel
   php artisan shdf:check-status 136883100331

2. If it shows an inconsistency, reset it:
   php artisan shdf:reset-status 136883100331 --stage=basic

3. Done! Student can now access and fill the form.

WHAT THESE COMMANDS DO:
-----------------------
- First command: Shows you what's wrong (status says completed but data is missing)
- Second command: Fixes the status by setting basic_completed back to false

AFTER RUNNING THE FIX:
---------------------
- Student 136883100331 can access: http://localhost:4200/shdf/136883100331/basic
- They can fill out the form
- When they submit, status will be correctly set to completed
- They won't be able to access it again (which is correct behavior)

NOTE:
-----
If you need to reset other students or reset comprehensive form:
- php artisan shdf:check-status {student_id}
- php artisan shdf:reset-status {student_id} --stage=basic
- php artisan shdf:reset-status {student_id} --stage=comprehensive
- php artisan shdf:reset-status {student_id} --stage=all
